# Eva Tarot design notes

The supplied lotus-and-sun reference informs the sage and muted gold accents on a strict cream/light background. The logo remains an actual lotus mark; the product name is now Eva Tarot. Inter handles conversation UI and Cormorant supplies short editorial headings. English and Vietnamese font subsets are self-hosted.

The prior supplied videos and Om Mani inspiration informed gentle motion, rounded navigation, breathing practice, daily reflection and small rituals. The current revision makes conversation the primary route: a clear question box, concrete examples, a suggested spread, one draw action, then a readable interpretation. Cards support the conversation and occupy less space than the former oversized reveal grid.

The full deck follows the user's exact requested order. Public-domain Rider–Waite–Smith illustrations preserve traditional symbolism without claiming to reproduce the copyrighted Gilded Tarot illustrations. The numbered library explains this explicitly.

Question suggestions and card-count recommendations are simple local rules. Interpretations and contextual follow-ups use a genuine local language model. UI never labels a static card reference as AI. A one-time setup panel explains model size, privacy boundaries and compatibility before download. The smaller model cannot promise ChatGPT-level quality.

Editing distinguishes metadata from interpretation: title/notes edits update the existing reading; a changed question branches into a new reading. The original remains accessible, so an old answer never silently appears to answer a different question.

On mobile, the composer remains above bottom navigation, all controls target at least 44px, and 78 manual card positions live in an optional scrollable number grid. Reduced-motion settings suppress animations. Card artwork has text labels and every reading remains usable as text.
